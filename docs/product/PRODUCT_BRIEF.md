# 제품 브리프

마지막 갱신: 2026-10-03 · 결정 D-007 · 정본 스펙 `PIVOT_DUOUNWAN_SPEC.md`

## 한 줄 정의
**둘운완**(DuoDone)은 연인·부부가 서로의 운동 약속을 봐주는 1:1 앱이다. 혼자선 미루는 운동, 둘이 보면 진짜 하게 된다.

> 둘이 보면, 진짜 하게 돼요.

`애인`은 기혼자에게 오해 소지가 있어 대외 문구에 쓰지 않는다(스토어 키워드 필드에만).

## 문제
- 운동 결심은 혼자 하면 아무도 모르니 쉽게 미뤄진다.
- 커플은 이미 서로의 하루를 묻는다. 하지만 "오늘 운동했어?"를 매번 카톡으로 묻는 건 잔소리처럼 느껴진다.
- 앱이 대신 묻고, 사진 한 장으로 답하고, 짝꿍은 한 번 탭으로 인정하면 확인이 가볍고 따뜻해진다는 것이 제품 가설이다. `Assumption`

## 핵심 사용자
- 같이 운동하기로 했지만 혼자서는 미루는 20~30대 연인·부부.
- 한쪽만 운동해도 된다. 짝꿍은 봐주고 인정하는 역할만 해도 루프가 돈다.

## 핵심 가치
- **약속**: 운동 종류·요일·마감 시각이 있는 운동 약속을 1화면에서 건다.
- **인증**: 오늘 예정이면 하루 종일 "오늘 운동했어?"가 뜨고, 인증샷 한 장으로 끝난다.
- **인정**: 짝꿍이 사진을 보고 원탭 리액션으로 인정한다.
- **가시성**: 마감이 지나도 기록이 없으면 짝꿍이 안다. 짝꿍은 응원하거나 똑똑한다.
- **둘운완**: 둘 다 해낸 날이 이어지는 연속 기록과 공유 카드.
- **내기**: 치킨·커피·설거지 같은 비금전 내기.

## 제품 원칙
- 행동은 작게, 확인은 한 번 탭으로.
- 감시가 아니라 "봐준다/인정해준다". 불인정·반려 버튼은 없다.
- 공유 범위는 연결된 짝꿍 1명뿐이다. 인증샷은 EXIF·위치 정보를 지우고, 연결을 끊으면 더 이상 볼 수 없다.
- 돈이 오가는 내기는 지원하지 않는다.
- 효과를 보장하지 않는다. 외부 연구 수치는 긴 설명에서 출처와 함께 "연구 소개"로만 쓴다(Wallace 1995 `Evidence`, stickK `Signal`). 이 앱의 효과는 아직 `Assumption`이다.

## 용어와 톤
| 개념 | 사용자 용어 | 코드/데이터 (변경 금지) |
|---|---|---|
| 상대 | 애칭 → 표시 이름 → `짝꿍` | `partner`, `manager` |
| 약속 | 운동 약속 (레거시 비운동 약속은 `약속`) | `plan` |
| 했어 기록 | 오운완 인증 / 사진이 있으면 인증샷 | `completedDates`, action `done` |
| 상대 확인 | 인정 (❤️🔥💪👏) | `verifiedDates`, `verifiedBy`, `actions.reaction` |
| 재촉 | 똑똑 | `poke` |
| 보상/벌칙 | 내기 — 지키면 / 못 지키면 | `promise` |
| 둘 다 해낸 날 | 둘운완 | 클라이언트 파생 |

- 앱이 하는 말은 해요체, 짝꿍끼리 오가는 말(주요 버튼·똑똑·답장)은 반말.
- `{name}님` 금지. 이름 뒤에는 받침 무관 조사(`한테`, `의`, `하고`)만 쓰고, 필요하면 `withJosa` 헬퍼를 쓴다.
- 영어 용어: partner / workout promise / props(인정) / knock(똑똑) / bet(내기). 마케팅 확인 대기(`S2` 레인 선택).
- 사용 금지어: `실천 메이트`, `공부`, `스터디`, `파일럿`, `Nod&Try`, `Nodtry`, `그래,해봐`(기존 사용자 1회 공지 키 `pivotNoticeTitle`만 예외).
