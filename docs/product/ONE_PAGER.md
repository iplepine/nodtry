# Nodtry 한 장 요약

마지막 갱신: 2026-07-30

## 한 줄 정의
Nodtry(그래,해봐)는 혼자 미루는 작은 약속을 알아봐 주는 단 한 명의 실천 메이트와 이어가는 1:1 실천 앱이다.

> 혼자 미루는 약속, 알아봐 주는 한 사람과 이어가요.

## 풀려는 문제
- 개인 목표 앱은 기록은 쉽지만 포기는 더 쉽다. 알림은 무시되고, 실패는 혼자 묻힌다.
- 혼자 세운 약속은 아무도 모르기 때문에 미뤄도 쉽게 묻힌다.
- 사용자는 더 복잡한 루틴 관리보다 오늘 했는지 알아봐 주고 다시 시작을 묻는 한 사람이 필요하다.
- 한 사람의 확인이 다음 실천율을 높이는지는 아직 가설이며, 4주 파일럿에서 검증한다.

## 핵심 사용자
- 혼자 루틴을 유지하기 어렵고 스스로를 못 믿는 성인.
- 자신의 작은 약속을 알아봐 줄 한 사람을 초대할 수 있는 사람.
- 학습·운동·회복·생활관리처럼 반복 실천이 중요한 사람.
- 1차 vertical: 성인 학습자(4주 스터디 실천 메이트 스프린트).

연인·친구·가족·동료는 실천 메이트가 될 수 있는 예시일 뿐, 특정 관계를 제품 타깃으로 삼지 않는다.

## 목표
- **단기**: 한 명의 실천 메이트와 연결되는 실천 루프(연결 → 계획 → 실행 → 확인 → 다음 실천)가 끝까지 작동하는지 검증.
- **MVP 성공 기준**:
  - 신규 사용자가 10분 안에 실천 메이트 연결 + 첫 플랜 생성을 완료한다.
  - 첫 주에 연결 사용자 40% 이상이 3회 이상 실천 기록을 남긴다.
  - 실천 메이트 확인/리액션을 받은 사용자의 다음 실천율이 미수신 사용자보다 높다.
- **장기 방향**: 1:1에서 다대다 책임망으로 확장(`docs/product/RESPONSIBILITY_NETWORK.md`).

## 작동 루프
1. **연결** — 나의 실천을 알아봐 줄 한 사람에게 초대 코드를 보내 1:1 실천 메이트로 연결한다. 양방향 관계 1쌍만 허용.
2. **계획** — 카테고리(공부/운동/직접) → 추천 약속 → 요일·알림·설명 4단계로 작은 실천 플랜을 만든다. 실천 메이트 미연결 시 즉시 active, 연결 시 메이트 승인 후 active.
3. **실행** — 지금 탭 상단 카드(오늘 할 일/지연/완료/빈 상태) 좌우 스와이프 캐러셀에서 "했어/휴식/건너뜀" 처리. 즉석 집중 타이머로 "지금 할게!"도 가능.
4. **확인** — 실천 메이트는 상대 실천을 알아보고 리액션·코멘트를 보낸다. 약속 시간이 지나면 미실천이 혼자 묻히지 않고 메이트에게 자동 전달되며, 메이트는 "똑똑"으로 다시 이어준다.
5. **정산** — 보상/벌칙 약속을 미리 합의해두면 기간 종료 시 완료 일수 기준으로 자동 정산하고 결과 카드로 양측에 노출한다.
