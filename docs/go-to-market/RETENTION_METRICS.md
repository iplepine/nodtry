# 유지 지표

## 핵심 루프
실천 메이트 초대/연결 → 작은 플랜 생성 → 오늘 실천 → 실천 메이트 확인/응원 → 다음 실천 → 4주 완료 → 같은 사람과 다음 플랜 생성

핵심 가설은 `한 사람의 피드백을 받은 뒤 다음 예정 행동을 완료할 확률이, 피드백이 없었던 경우보다 높다`이다. 파일럿 전에는 검증되지 않은 `Assumption`이며, 아래 지표는 효과를 증명했다는 표현이 아니라 가설을 검증하기 위한 측정 기준이다.

## 4주 스터디 실천 메이트 스프린트 목표

| 지표 | 성공 기준 | 실패 기준 | 해석 |
|---|---:|---:|---|
| D1 활성화 | 60% 이상 | 35% 미만 | 첫날 `partner_connected` 또는 첫 플랜 생성 |
| W1 실천 | 40% 이상 | 25% 미만 | 첫 7일 내 3회 이상 실천 |
| W1 실천 메이트 피드백 | 50% 이상 | 30% 미만 | 첫 7일 내 `partner_feedback_sent` 1회 이상 |
| 4주 의미 완료 | 25% 이상 | 15% 미만 | 28일 중 12일 이상 실천 또는 정산 완료 |
| 같은 사람과 다음 플랜 의향 | 30% 이상 | 15% 미만 | 종료 후 7일 내 같은 실천 메이트와 다음 플랜 생성 또는 명시 의향 |
| 유료/보증금 의향 | 10% 이상 | 5% 미만 | 9,900원 이상 재참여 또는 보증금 참여 의향 |

## 활성 지표
- D1 활성화: 가입 후 24시간 내 `partner_connected` 또는 첫 플랜 생성
- W1 실천: 첫 7일 내 실천 기록 3회 이상
- W1 실천 메이트 피드백: 첫 7일 내 `partner_feedback_sent` 1회 이상
- 4주 완주: 시작한 플랜의 완료 또는 의미 있는 정산

## 유지 지표
- D7 리텐션
- D30 리텐션
- 주간 실천 기록 수
- 실천 메이트 피드백 수신 후 다음 실천 전환율
- 피드백 없음 구간의 다음 실천 전환율
- 피드백 후와 피드백 없음 간 다음 실천율 차이
- 플랜 완료 후 7일 내 같은 실천 메이트와 다음 플랜 생성률

## 핵심 가설 측정

| 측정 | 산식/기록 | 해석 |
|---|---|---|
| 초대 완료율 | 초대 발송 대상 중 초대 링크를 열거나 가입을 시작한 비율 | 초대 메시지와 진입 마찰 확인 |
| 연결 완료율 | 초대 발송 대상 중 `partner_connected`까지 완료한 비율 | 실천 메이트 루프 진입 가능성 확인 |
| 피드백 발송률 | 피드백 가능 행동 중 `partner_feedback_sent`가 발생한 비율 | 한 사람이 실제로 확인해 주는지 확인 |
| 피드백 지연 | 실천 완료/놓침 노출 시각부터 `partner_feedback_sent`까지의 시간, 중앙값과 범위 | 피드백이 다음 예정 행동 전에 도착하는지 확인 |
| 피드백 후 다음 실천율 | 피드백 수신 뒤 첫 번째 예정 행동 중 `study_action_completed` 비율 | 핵심 가설의 노출군 지표 |
| 피드백 없음 다음 실천율 | 직전 행동 뒤 피드백 없이 맞은 첫 번째 예정 행동 중 `study_action_completed` 비율 | 핵심 가설의 비교 지표 |
| 다음 실천율 차이 | 피드백 후 다음 실천율 - 피드백 없음 다음 실천율 | 양의 방향인지 확인하되 10쌍 표본에서 인과로 단정하지 않음 |
| 체감 반응 | 확인을 `응원` / `감시` / `부담`으로 느낀 응답과 이유 | 제품 신뢰와 지속 가능성 판단 |
| 같은 사람과 지속 의향 | 종료 후 같은 실천 메이트와 다음 4주를 이어가겠다는 비율 | 관계 유형이 아닌 1:1 루프의 유지 의향 판단 |

연인, 친구, 가족, 동료는 실천 메이트의 선택 가능한 관계 예시로만 기록한다. 관계 유형별 성과 비교는 파일럿의 모집 세그먼트나 성공 판단으로 사용하지 않는다.

## 위험 신호
- 실천 메이트 초대 후 `partner_connected` 미완료 증가
- 첫 플랜 생성 후 첫 실천 미발생
- 실천 메이트 확인 없는 일방 기록 증가
- 똑똑 수신 후 앱 미방문
- 실천 메이트가 부담을 느껴 확인을 중단
- 사용자가 확인을 응원보다 감시로 해석
- 사용자가 학습량보다 앱 관리에 피로를 느낌
- 타이머/랭킹 기능 요구가 핵심 루프보다 커짐

## 목표 가설
- 첫 주 실천 메이트 연결률 60% 이상
- 첫 주 3회 이상 실천율 40% 이상
- 피드백 후 다음 실천율이 피드백 없음 구간보다 높은 방향
- 플랜 완료 후 같은 사람과 다음 플랜 생성/지속 의향 30% 이상

## 측정 이벤트

파일럿에서 최소한 아래 이벤트는 수동 집계라도 남긴다. 고객 화면과 운영 문구에서는 `실천 메이트`를 사용하지만, 기존 코드·데이터 이벤트 ID와 내부 필드의 `partner_*` 명칭은 변경하지 않는다.

- `pilot_joined`: 파일럿 참여자 등록
- `partner_connected`: 실천 메이트 연결 완료
- `study_plan_created`: 스터디 플랜 생성
- `study_action_completed`: 오늘 학습 실천 완료
- `partner_feedback_sent`: 확인, 응원, 똑똑 발송
- `plan_adjusted`: 요일, 알림, 행동 조율
- `pilot_settled`: 4주 정산 확인
- `next_plan_intent_recorded`: 다음 4주 의향 기록
- `paid_intent_recorded`: 유료/보증금 의향 기록
